# HerTechTrail Student Directory

## Project Overview

The HerTechTrail Student Directory is a simple webpage created as part of the Mid-Cohort Project for the Frontend Web Development Pro program.

The project demonstrates the use of JavaScript arrays and objects to store and display information about students.

## Features

The Student Directory displays:

- Student name
- Course
- Level
- Location
- Short bio

The project contains 20 student objects stored inside a JavaScript array.
